## Findings

1. Gate under-checks copper weight: gate.py:74-87 built kwargs without copper_oz, so
   dfm_check.run's 1.0 default applied on every gate run. pd-trigger is 2 oz (P5-digest
   "capability class 2layer_2oz") but its live P9 gate judged against 0.127 mm
   (2layer_1oz) floors, not 0.1524 mm. Survived only because min trace is 0.2 mm; a
   2 oz board routed 0.13-0.15 mm would false-pass. Bench masked it: manifest.yaml:263
   had to inject copper_oz 2.0 manually. FIXED (P9-1).
2. Release completeness circular: check_release derived expected inner layers from the
   layer count FOUND in the fab dir (dfm_check.py:488,566). A 4L export dropping BOTH
   inners audited as a clean 2L board under 2L floors - the board's own layer list
   (fab_export.copper_layers) never consulted, defeating the independent-second-path
   claim for exactly the defect class it exists for. Latent, never observed. FIXED (P9-2).
3. Empty/open Edge.Cuts silently disables checks: gerblib returns empty Polygon on
   unpolygonizable outline (gerblib.py:253-265); check_copper_to_edge / check_holes
   early-return on outline.is_empty with no violation (dfm_check.py:184-186,234-236).
   FIXED (P9-2).
4. Paste-without-mask-opening unmodeled: FabStack scanned paste_files (gerblib.py:205)
   but no check read them - fully tented SMD pad (unsolderable, classic wrong-layer
   export defect) only caught at P10 API audit / human JLCDFM, one phase late. FIXED (P9-3).
5. 19 dfm_silk_over_pad warnings on pd-trigger: easyeda2kicad 0.06 mm fp_circle pin-1
   artifact drawn INSIDE pad 1 (fixture R0603.kicad_mod:22). Pre-T3 library; fpfix rule A
   deletes exactly this at pull time (dry-run: 13/16 footprints). Fixture keeps them
   honestly as board defects - no calibration change.
6. Stale prose: SKILL.md:149 says P10 latch is "gerber-sha-bound" but T1 rebound it to
   design_sha256 (order_submit.py:698). Verified live: 3 zips, 3 file shas, 1 design hash
   (20688e73..). Ladder row 140; edit reserved to orchestrator.
7. jlc_capabilities.yaml over-claims: 3 keys per profile (min_pad_size_mm,
   min_silk_height_mm, min_solder_mask_clearance_mm) consumed by NO check; remaining
   JLCDFM classes covered at P10/human per V6. DOCUMENTED (P9-5).
