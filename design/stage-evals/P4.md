  every board (blinky2 fixture 27 overlaps, shipped pd-trigger 5). -> P4-1.
- CORRECTION (V19, prominent): eval diagnosed schlib.stub_dir as having the wrong 90-deg
  rotation sign (LEARNINGS.md:957-962 inward-stubs observation). The rotmirror fixture
  FALSIFIED this: stub_dir was CORRECT at every rotation. Real defect was kicad-sch-api
  get_component_pin_position mirroring pin positions through the anchor at 90/270 (fixed in
  schlib.pin_pos, point reflection; 0/180 untouched so goldens byte-stable). Fixture also
  exposed a defect the eval missed: to_page composed mirror BEFORE rotation while KiCad
  rotates first - swaps pins of a rotated+mirrored part, invisible to ERC (pin position set
  unchanged), caught only by the per-pin netlist leg. LEARNINGS:2245, ladder row 177.
- Bench P4 scored root sheet only; 2 of 4 P4 boards hierarchical, sheet_balance degenerate
  at 1.0 on all fixtures (bench.py score_p4 read one file; sch_metrics already took a list).
- ERC 0/0 structurally vacuous on pulled-symbol boards: lib_pin_types retypes non-supply pins
  passive, so driver-conflict/undriven checks inert (carrier P4-digest:18-23 honesty item).
  Pin-level coverage rides entirely on the reviewer.
- netlist_audit ignored constraints.json placement refs: refdes rename/split silently muted
  placement constraints (pd-trigger R2A/R2B split, finding 31; walk existed only in bench P2).
- Hierarchical netlist exports drop no-connect singleton nets: forgotten pin reaches P5 with
  no net, nothing reports it (usb-buck digest P5 watch; LEARNINGS.md:650).
- Two unguarded schlib hazards: label anchor on a foreign wire run silently merges nets;
  power_flag VALUE derived from symbol name while wire label came from net arg (mismatch =
  silently wrong global net). Survived by convention only.
