## Findings

- power_no_consumers false positive on rails whose loads are all passive pins - the check
  counted only pintype power_in (netlist_audit.py:284-292 pre-fix). All 9 missing bench points
  on pd_trigger_arch were this: VBUS/-VAUX/-VIND all feed real loads through F1/R14/LED
  resistors on a shipped working board. Check defect, not board defect.
- architect.md's constraints.json enumeration omitted T2 keys voltage_pairs/coating; 6/6 runs
  emitted neither. lumina-carrier hand-hacked the 114V PoE differential as +57/-57 node
  voltages (POE_TAP_A1/A2 both 57V derive 0V apart) - the exact case voltage_pairs exists for.
- rules_gen never consumed voltages/voltage_pairs (grep-verified), so P2-declared HV clearance
  reached the router only via hand-written DRU; on carrier the hand DRU dropped the aiee_*
  fab floors -> 189 DFM errors at drc_routed 0/0 (LEARNINGS.md:1939-1956).
- constraints.json placement/thermal refs never validated at the P4 gate; place_anneal
  silently drops unresolvable refs (documented R2 -> R2A/R2B near-miss; ladder row 86).
- architecture/ vs kicad/ constraints.json diverge post-P5 with no drift detection - stale
  current rating gave 61 vs 53 undersized_track depending on file loaded (LEARNINGS.md:1929,
  ladder row 154).
- sim-analyst P2 leg never spawned: 0/6 workspaces have kicad/sims/ despite three boards with
  textbook-simmable blocks in sim-analyst.md's explicit in-scope list. Trigger ("nontrivial
  analog content", SKILL.md:155) was unscripted judgment.
- Hierarchical netlist export drops NC singleton nets, so NC pads reached board_init with no
  net and no report (LEARNINGS.md:650, ladder row 68).
- Residual (no fix landed): P2 asserts routing-geometry premises unverifiable before
  footprints exist - pd-trigger's "1.75mm VBUS end-to-end, no vias" falsified at P7 (J1 pads
  pinch 1.465mm); cost a route rework. 1/6 runs; accepted as inherent stage ordering.

only when the architect nominates sim candidates and sim-analyst actually spawns (P2-6).

  judgment at a blocking human checkpoint. Cheapest place in the pipeline to NOT economize.

  calibration loop; escalate to fable/high only when the architect flags a novel analog
