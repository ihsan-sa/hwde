## 2026-10-08 [state][gates][check_model_paths] A model-path rewrite stales every gate that hashes the board

Two tempting fixes are wrong. Stripping model paths from the pcb hash weakens verify, because check_model_paths runs in the verify suite and a hand edit of a path must still stale it. Changing a normalizer also changes every stored pcb hash at once (gate inputs, the artifact registry, report input digests, release attestations), so every board in the boards repo would read stale. Instead --fix now moves the passed gates recorded against the exact pre-fix board to the new hash (State.restamp_input), after proving the rewrite touched nothing but model paths. A board already rewritten by an older --fix cannot be re-stamped from state alone, because its pre-fix hash is gone: put the pre-fix .kicad_pcb back from git and run --fix again, which rewrites it to the same bytes and keeps the gates fresh.
